# Prefix Removal Tool
*This script is for a lab environment and meant for learning purposes only*

This is a very simple raw script used for removing prefixes from hundreds of filenames.
One day, I had a folder with hundreds of files on it - I needed to remove all the prefixes from every filename, on the 11th file, doing manual (right-click -> rename -> highlight prefix -> delete), is really tedious. This simple tool saved my sanity

## Note
Be sure to run the script with `-whatif` first before committing
